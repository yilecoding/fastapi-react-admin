<SectionTitle id="why" title="One rewrite, distilled into a base you can start building on" more="Why we built it" href="getting-started/introduction/">

AI keeps adding systems worth building, yet every new one starts by redoing login, permissions and approvals. This project started as a rewrite of a few small Java + Vue 2 systems on FastAPI + React 19, keeping everything that gets rebuilt every time — so the next system starts with business logic.

</SectionTitle>
