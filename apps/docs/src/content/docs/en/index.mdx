<SectionTitle id="whats-in-the-box" eyebrow="WHAT'S IN THE BOX" title="The parts every internal system ends up needing">

Users, roles and departments are the easy part. These are the pieces that usually get rebuilt from scratch.

</SectionTitle>

<div class="features">
  <Feature title="Row-level data permissions" icon="rows" href="features/data-permissions/" more="How it works">
    Beyond menus and buttons, a role decides which **rows** a user sees. A department manager opening the user list only gets their own department.
  </Feature>
  <Feature title="Tabs that keep their state" icon="tabs" href="features/multi-tab/" more="How it works">
    Built on React 19's `<Activity>`: a half-filled form, the page you were on and an expanded tree are still there when you switch back. Filters live in the URL, so a refresh keeps them too.
  </Feature>
  <Feature title="Approval workflow" icon="flow" href="features/approval-workflow/" more="How it works">
    Form designer and flow tree with or-sign / co-sign, send back, transfer, take back, add approvers and timeouts.
  </Feature>
  <Feature title="An AI assistant that can't overreach" icon="sparkles" href="features/ai-assistant/" more="How it works">
    Tool calls run as the signed-in user, inside their permissions and data scopes. Writes are previewed and run only after the user confirms; every call is audited.
  </Feature>
  <Feature title="Large files, handled" icon="upload" href="features/file-storage/" more="How it works">
    Local disk or S3-compatible storage, instant upload by hash, parallel chunks and resume after a page refresh.
  </Feature>
  <Feature title="Pick your database" icon="database" href="features/databases/" more="How it works">
    PostgreSQL, SQL Server or MySQL with the same code and the same migration chain.
  </Feature>
</div>

<CtaBand title="Running locally in five commands" primary={{ text: 'Quick start', href: 'getting-started/quick-start/' }} secondary={{ text: 'What it is and how it compares', href: 'getting-started/introduction/' }}>

```bash
docker compose -f docker-compose.dev.yml up -d          # PostgreSQL + Redis
pnpm install:all
cp apps/api/backend/.env.example apps/api/backend/.env
pnpm db:init                                            # tables + seed data
pnpm dev                                                # open http://localhost:8888
```

</CtaBand>
