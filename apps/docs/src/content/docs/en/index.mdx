<SectionTitle id="why" title="One rewrite, distilled into a base you can start building on" more="Why we built it" href="getting-started/introduction/">

AI keeps adding systems worth building, yet every new one starts by redoing login, permissions and approvals. This project started as a rewrite of a few small Java + Vue 2 systems on FastAPI + React 19, keeping everything that gets rebuilt every time — so the next system starts with business logic.

</SectionTitle>

<div class="feature-lines">
  <FeatureLine title="Tabs that keep their state" href="features/multi-tab/">Built on React 19's Activity: a half-filled form and the page you were on survive switching back</FeatureLine>
  <FeatureLine title="Approval workflow" href="features/approval-workflow/">Form designer and flow tree with or-sign / co-sign, send back, transfer, add approvers and timeouts</FeatureLine>
  <FeatureLine title="An AI assistant that can't overreach" href="features/ai-assistant/">Tools run as the signed-in user; writes are previewed and confirmed first, and every call is audited</FeatureLine>
  <FeatureLine title="Large files, handled" href="features/file-storage/">Local disk or S3-compatible storage, instant upload by hash, parallel chunks, resume after refresh</FeatureLine>
  <FeatureLine title="Pick your database" href="features/databases/">PostgreSQL, SQL Server or MySQL with the same code and the same migration chain</FeatureLine>
  <FeatureLine title="Open API" href="features/open-api/">AK/SK signing, rate limits and call logs, with Python / Node / Java SDKs and webhooks</FeatureLine>
  <FeatureLine title="Messages and notifications" href="features/notifications/">Real-time inbox, scoped announcements, and email / SMS / chat-bot routing per event</FeatureLine>
  <FeatureLine title="Desktop and mobile" href="features/clients/">An Electron desktop template and an Expo mobile template — start from a template, not from zero</FeatureLine>
  <FeatureLine title="Everything else" href="features/overview/">Sign-in security, import / export, scheduled jobs, monitoring and logs, listed by area in the overview</FeatureLine>
