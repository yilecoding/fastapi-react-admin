<SectionTitle id="为什么做它" title="一次重构，沉淀成一个拿来就能写业务的底座" more="为什么做它" href="getting-started/introduction/">

AI 让要做的系统越来越多，可每个新系统开头都在重复登录、权限、审批这批活。这个项目起步于几套 Java + Vue 2 小系统的重构：用 FastAPI + React 19 从头搭一遍，把每次都要重做的部分沉淀下来——下一个系统，从写业务开始。

</SectionTitle>
