<SectionTitle id="为什么做它" title="一次重构，沉淀成一个拿来就能写业务的底座" more="为什么做它" href="getting-started/introduction/">

AI 让要做的系统越来越多，可每个新系统开头都在重复登录、权限、审批这批活。这个项目起步于几套 Java + Vue 2 小系统的重构：用 FastAPI + React 19 从头搭一遍，把每次都要重做的部分沉淀下来——下一个系统，从写业务开始。

</SectionTitle>

<div class="showcases">

<Showcase wide title="Web · 桌面 · 手机，一个仓库" lead="后端、Web 后台、桌面端模板、移动端模板和文档站，都在同一个 pnpm + turbo monorepo 里。" href="getting-started/introduction/#一个仓库里有什么" more="看仓库结构">

- Web 管理后台是主体，开箱即用
- 桌面端模板直接加载 Web 的构建产物，只补静默打印、本地硬件和自动更新
- 移动端模板是原生界面，和 Web 共用接口类型与语言包
- 依赖严格单向，`pnpm arch:check` 在 CI 里把关
