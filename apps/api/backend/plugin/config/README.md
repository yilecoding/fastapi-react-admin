# Config

参数配置插件，通常用于动态维护系统参数和前端工程展示所需的配置数据

- 支持维护系统参数配置
- 适合前端工程展示数据和系统级动态参数场景

## 插件类型

- 扩展级插件
- 扩展目标：`admin`

## 配置说明

`CONFIG_ENCRYPT_SECRET_KEY`：参数密钥的落库加密密钥。在环境变量或 `.env` 中配置，推荐 32 字节的十六进制字符串：

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

- API、worker 使用相同密钥，妥善备份，升级后不要随意更换。
- 未配置或格式不合法时，拒绝保存非空密钥；普通配置和空密钥不受影响。
- 管理读接口的密钥 `value` 恒为空，`is_secret` / `is_configured` 表示是否为密钥、数据库中是否有值；不返回密文或原密码的片段。
- 更新密钥时 `value` 留空或不传表示保留，非空表示替换；`clear_secret: true` 显式清空，不能同时传新值。普通配置仍用空字符串清空。
- 已有配置键名不能修改；密钥不允许标记为前端可读。

### 从旧版本升级

1. 停止旧版本 API 和 worker，避免升级期间继续写入明文或旧缓存。
2. 若数据库中有非空密钥，先为 API、迁移和 worker 配置相同的 `CONFIG_ENCRYPT_SECRET_KEY`。
3. 执行 `pnpm db:upgrade`，迁移加密存量敏感值（含软删除行），可重复执行。需要在线数据库连接；缺密钥或已有密文不能解密时停止升级。
4. 启动新版本 API 和 worker。新版本不再缓存原始配置，API 启动时清理历史 Redis / 本地配置缓存。
5. 轮换此前可能通过读接口泄露的 SMTP 授权码。

迁移回滚保留密文，不会重新生成明文；旧版本无法直接读取新格式，回退旧程序需要恢复升级前的数据库备份。

## 使用方式

1. 安装并启用插件后，重启后端服务
2. 通过系统后台页面或 Swagger 管理参数配置数据

## 卸载说明

- 卸载前先确认没有业务依赖密钥配置，仍需读取历史密文时保留加密密钥
- 如业务代码或前端页面已依赖参数配置能力，请同步清理对应集成
